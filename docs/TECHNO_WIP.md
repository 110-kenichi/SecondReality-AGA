## 1. ソースから確定した事実

### 1.1 `init_interference` (KOEA 646-745)

1. `_circle2` (8,000 = 1 plane) を VGA ページへ blit。
   - 1 ソース行 = 40 バイト (320px)。`bltline` が通常、`bltlinerev` が
     鏡像を書き、合わせて 80 バイト (640px) の 1 行になる。
   - 上 200 行 (di) と下 200 行 (bp、上下反転) を作る。
2. `vram` を `circles[0..7]` へコピーし、`rotate1` で 1 bit ずつ
   右シフトした 8 ページを作る。
3. **その後で** `_circle` (24,000 = 3 planes) を VGA ページへ blit。

→ `do_interference` が読む `circles[]` には **`_circle2` しか入らない**。
`_circle` はコピー後のページに書かれるため、干渉円表示には使われない。

### 1.2 `do_interference` (KOEA 747-910)

- 1 ページ = 400 行 × 80 バイト = 32,000 バイト。
  1 ソース行は「通常 320px + 鏡像 320px」。
- **プレーン 0..2 は `init_interference` が書いた静的 `_circle`**。
  `do_interference` は `PLANE 8` (プレーン 3) だけを書く。プレーン 3 の
  元データは `circles[]` に入っている `_circle2`。
- 200 行について:
  ```
  bp = sinurot + 14 + 18*(y+1)          ; バイトオフセット
  bx = sin1024[bp / 2] >> 3             ; MASM の _sin1024[bp] はスケールなし
  ax = (s8)power0[sinuspower][bx & 0xff] - scrnposl + overx
  page = 7 - (ax & 7)                   ; サブバイト用の 8 ページ
  si = scrnpos + y*80 + overya + (ax >> 3)
  ```
- `rotate1` は 32,000 バイトを 1 bit 右シフト。8 ページ分を回す。
- `si` は 16bit。ページのセグメントは 2,048 パラグラフ =
  32,768 バイトなので、`si >= 32768` は次のページ (pg+1) を読む。
- **8 ページ回転と pixel pan (`scrnposl`) は打ち消し合う**。表示は
  - ピンク (`_circle`, plane 0-2): `(scrnx + x, scrny + y)`
  - 銀 (`_circle2`, plane 3): `(overx + d - 7 + x, overy + y)`
    (`d = power0[sinuspower][(sin1024[bp/2]>>3)&0xff]`)
- `bp & 2047` は **バイト**マスク。1,024 語 (2,048 バイト) の正弦波表を
  そのまま読み切る。語添字と誤解して表の後ろのコードを読むと、
  走査線ごとの不規則なシフトになりノイズ状になる。
- パレットは KOEA の `pal1` (色 0..7, 8/9 グレー系) と
  `pal2` (色 8..15, 7/9 紫系)。どちらも 16 エントリで、8 個の窓を
  `palanimc` (3 バイト単位, 0..21) で回す。`patdir=-3`。

### 1.3 `power0` と `sin1024`

- `power0[16][256]` (KOE.C 173-211):
  - `b=0..14`: `a = (c>127)? c-256 : c; value = a*b/15`
  - `b=15`: `value = c`
- `sin1024` は 1,024 エントリ、-256..256 (SIN1024.INC)。
- `sinuspower` は 5 秒後 (70*5 フレーム) から 16 フレームごとに 15 まで増える。

### 1.4 `dointerference2` (KOEB 304-607) — 冒頭の静的フェーズ

- `KOE.C` は `dointerference2()` を `initinterference()` の前に呼ぶ。
- 中身は **256 フレームのパレットフェード**。`jmp @@OVER3` で
  パターン描画ループを飛ばしているため、**スクロールしない**。
- VGA ページ 0 には `init_interference` が書いた `_circle` (3 planes) の
  静的パターンが残る。表示窓は `scrnx=160, scrny=100` (sizefade=0)。
- パレットは `pal0` (index 0 と 8 が (0,30,40) の暗い緑)。
  `palfader` が 0→512 まで 2/frame で増え、`mixpal` が
  フェード (0..256) → 明るさ加算 (256..512, 63 で飽和) を行う。
  `palanimc` は `patdir=-3` で 3 バイトずつ回転。
- 実測: 暗い緑 (0,36,48) → (0,117,158) → 白 (255,255,255)。
  参照動画の 169〜172 秒 (暗緑 → 白フラッシュ) と一致。
- **KOEB と KOEA は別モジュール**なので、KOEA の `scrnx/scrny/...` は
  KOEB の値 (224/100...) を引き継がず、**0 から始まる**。

## 2. 実装済み

### 2.1 遷移 (KOE.C 224-315)

- `flash(-1)` で干渉円のパレットを保存し、32/64/192/256 の 4 段階で
  白へブレンド (各 1 フレーム)。
- `memset(vram,0,64000)` (全プレーン) → `memset(vram,255,8000)` で
  白画面。パレットをランプ `(a*3, a*3.5, a*4)` に。
- 4 回の縦ワイプ。1 回 21 フレームで、`zya++ ; zy += zya` の加速で
  行 0..199 まで伸びる。`b*10` バイト = 80px 幅を黒 (0) にする。
  各フレームで `flash(a)`、a = 256,224,...,0。最後に白フラッシュ 4 段。
- 実測のワイプ色 (182,211,243) は参照 188 秒の (182,210,242) と一致。

### 2.2 `doit1/2/3` (KOE.C 342-586, KOEA `asmdoit`)

- Mode X の **4 プレーン × 8 ページ**。`vplane[4][8*8192]` を
  `doit3` では 16KB ページ (plv は偶数) として使う。
- 毎フレーム:
  1. `vbuf` (320x200 1bpp) をクリア。
  2. 11 個の平行四辺形 (`c=-10..10 step 2`) の 4 辺を XOR 描画。
     `asmbox`/`drawline` 相当で、**y 主軸・1 走査線 1 ピクセル**。
     水平線 (`dy==0`) は描かない。
  3. `blit16`: 各行を prefix XOR で塗りつぶし、`pl` のプレーンへ
     書く。キャリーは `carry ^= parity8[in]` で次バイトへ引き継ぐ
     (これが 8px 周期のギザギザの原因だった)。
  4. 表示ページ = 書き込んだページ `plv`。CRTC スタートは
     `plv*0x2000` (+ `doit3` は `xpos/8`)。
- `doit1`: rot=45, rot+=2, vm=50 (vx,vy を vm/100 倍), 70*6 フレーム。
- `doit2`: rot=50, rot+=rota/10, rota++, vm=6400
  (vx,vy を (vm/64)/100 倍), 70*12 フレーム。
- `doit3`: 80 バイト/行、パターンは +40 バイトに書く。`xpos` は
  最後の 333 フレームで 320→640 に増え、CRTC の開始バイト
  `xpos/8` でパターンが左へ流れて画面外へ出る (左スライドアウト)。
  plv は +2 ずつ。
- パレットは KOE.C の `pal[16][16][3]`。`waitborder()` が音楽行 7 で
  `curpal=15` に戻し、1 フレームごとに 1 段暗くする。
- **注意**: 表示開始アドレスは「ページ先頭 + CRTC 開始バイト」。
  パターンの書き込みオフセット (+40) を表示側でも足すと、
  40 バイトずれた扇状のパターンになる。

### 2.3 TROLL (KOE.C 588-727)

- `TROLL.UP` は 320x400 の 8bit 画像 (`troll.bin` / `troll.pal`)。
  320x256 画面へ縦に拡大して全画面表示する。
- 動き (参照 218-259 秒):
  - 右からスライドイン。左端にぶつかった瞬間に**画面が揺れ**、
    **映像だけが一瞬ホワイトアウト**する (背景は黒のまま)。
  - 静止 (約 6 秒)
  - 左へスライドアウト → 黒
  - 右から再スライドイン (同じく衝撃 + 白飛び)
  - ホールド + 減衰リップル (`sin1024` / `ripplep`)
  - **最後はブラウン管の消灯**: 上下に潰れて中央の水平線になり、
    さらに点へ縮み、減光して消える。白飛びするのは映像の画素だけで、
    画面の外側 (背景) は黒のまま。
- `doit3` の左スライドアウト完了後に自動で TROLL へ遷移。

### 2.4 ファイル

- `tools/techno_prepare.py`
  - `_CIRCLE.OBK` / `_CIRCLE2.OBK` を OMF から展開。
  - `TROLL.UP` を readp 形式から `troll.bin` + `troll.pal` に展開。
  - `SIN1024.INC` を `sin1024.bin` (1024 x s16 BE) に変換。
- `techno.c`
  - **Phase A (KOEB)**: `_circle` (3 planes) の 400x640 静的ページを構築し、
    窓 (160,100) を表示。`pal0` の `mixpal` フェードと `palanimc`
    回転を 256 フレーム行う。
  - **Phase B (KOEA)**: `_circle` (静的, plane 0-2) と `_circle2`
    (スクロール, plane 3) の 640x400 ページ。power0 の走査線シフト、
    KOEA の pal1/pal2。
  - **遷移 + doit1/2/3**: 上記 2.1 / 2.2。
  - **TROLL**: 上記 2.3。
- `run/make-hdf.ps1` が `circle0.bin` / `circle123.bin` /
  `sin1024.bin` / `troll.bin` / `troll.pal` を HDF へ入れる。
